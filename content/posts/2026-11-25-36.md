## RPG WOLFエディタ 2.x系だったので
でんけん青春日記は2017〜2018年に作られたゲームで、当時のWOLF RPGエディタ 2.x系で作られていました。<br />
そのまま `Data.wolf` を置いて起動してみると、コンソールに次のエラーが出て止まってしまいました。

```
The following game data could not be read or recognized as game data due to too old versions. Abort startup.
```

ブラウザウディタは 3.x系のデータ形式を前提にしているため、古いバージョンのデータは「古すぎる」として読み込めないようです。

そこで、最新の WOLF RPGエディタ（3.x系）でプロジェクトを開き直して保存し、ブラウザウディタ向けの Data.wolf を作り直しました。<br />
これで無事に起動するようになりました！

古いウディタ作品をブラウザ化したい場合は、まず 3.x系のエディタで開き直すのが近道です。

## GitHub Pages で動かなかった話
もう一つハマったのが、GitHub Pages に置いたときだけファイルの読み込みに失敗する問題です。<br />
コンソールを見ると、Data.wolfDefaultSoundFont.sf2Game.iniという明らかに複数のファイル名が混ざったような名前のファイルを取りに行って 404 になっていました。

本来は `Data.wolf`、`DefaultSoundFont.sf2`、`Game.ini` の3つのファイルのはずが、1つにつながってしまっています。

原因は InitialDownloadList.ini などの .ini ファイルの改行コードでした。
手元では CRLF だったのですが、Git の `core.autocrlf` によってリポジトリには LF で保存され、GitHub Pages からも LF のファイルが配信されていました。<br />
ブラウザウディタは CRLF で行を区切っているようで、改行が認識されず3行が1行として読まれていたわけです。

対策として `.gitattributes` を追加し、.ini ファイルの改行を Git に変換させないようにしました。

```
*.ini -text
*.wolf binary
```


追加したあとに .ini ファイルをコミットし直せば、CRLF のまま公開されます。

なお、一度古い Data.wolf を読み込んでいると、ブラウザ側にキャッシュが残ってエラーが続くことがあります。その場合は DevTools の Application → Storage →「Clear site data」でサイトのデータを消してから再読み込みしてください。

## まとめ
- 古い（2.x系の）ウディタ作品は、3.x系のエディタで開き直して Data.wolf を作り直す
- GitHub に置くときは .ini ファイルの改行コード（CRLF）に注意する
- うまく動かないときは、ブラウザのキャッシュ（サイトデータ）も消してみる

ちょっとハマりどころはありましたが、昔作ったゲームをブラウザでそのまま遊べるようになるのはとても嬉しいですね。
