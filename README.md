# denken-articles
電研ブログのmarkdownの記事や固定ページ、画像を保存するためのリポジトリ

環境設定は以下のリポジトリにて
- https://github.com/osu-denken/denken-hugo

## ディレクトリ構造
- `content/posts/`: 記事（Hugo の front matter）
- `static/images/`: 記事に使う画像

記事は `denken-hugo` のサイトに取り込んで公開します。
